Module: Livekit.Agents.Pipeline.TurnDetector

Config struct:
```elixir
defmodule Config do
  @type t :: %__MODULE__{silence_ms: pos_integer(), subscriber: pid()}
  defstruct silence_ms: 500, subscriber: nil
end
```

State struct:
```elixir
defmodule State do
  @moduledoc false
  @type vad_state :: :silence | :speaking
  @type t :: %__MODULE__{
    config: Config.t(),
    vad_state: vad_state(),
    silence_timer: reference() | nil,
    utterance_frames: [AudioFrame.t()]
  }
  defstruct config: nil, vad_state: :silence, silence_timer: nil, utterance_frames: []
end
```

Public API:
- start_link/1 — keyword opts [silence_ms: integer, subscriber: pid]; validates subscriber is a pid
- push_frame/2 — (pid, {classification, frame}) where classification is :speech | :silence; cast (non-blocking)
- reset/1 — cancels pending timer, clears utterance_frames; cast

GenServer callbacks:
- handle_cast({:push_frame, :speech, frame}, state):
  1. Cancel silence_timer if set (Process.cancel_timer)
  2. If vad_state was :silence: send {:turn_start, frame.timestamp_us} to subscriber
  3. Accumulate frame into utterance_frames
  4. Set vad_state :speaking, silence_timer nil
- handle_cast({:push_frame, :silence, frame}, state):
  1. If vad_state == :speaking: start timer via Process.send_after(self(), :silence_timeout, config.silence_ms)
  2. Store timer ref, do NOT clear frames yet
- handle_info(:silence_timeout, state):
  1. Send {:turn_end, state.utterance_frames} to subscriber
  2. Reset utterance_frames to [], vad_state to :silence, silence_timer to nil
- handle_cast(:reset, state):
  1. Cancel timer if set
  2. Return state with utterance_frames: [], silence_timer: nil, vad_state: :silence
