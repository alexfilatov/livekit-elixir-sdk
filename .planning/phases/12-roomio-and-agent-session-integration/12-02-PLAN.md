    ## Mock Strategy

    RoomIO calls three external modules: `Room.subscribe_events/2`, `AudioTrack.subscribe/3`,
    `AudioTrack.publish/2`, `AudioTrack.unsubscribe/1`, and `Pipeline.push_frame/2`.

    Use simple Elixir processes as stand-ins: the test process itself acts as both the
    "room" and the "pipeline" by receiving the calls via message passing.

    Because RoomIO calls `Room.subscribe_events(config.room_pid, self())`, we need a
    process that handles that GenServer.call. Spawn a minimal mock GenServer inline:

    ```elixir
    defmodule MockRoom do
      use GenServer
      def start_link, do: GenServer.start_link(__MODULE__, [])
      def init(_), do: {:ok, %{subscribers: []}}
      def handle_call({:subscribe_events, pid}, _from, state),
        do: {:reply, :ok, %{state | subscribers: [pid | state.subscribers]}}
      def handle_call(:room_ref, _from, state), do: {:reply, make_ref(), state}
      def handle_call(:nif_module, _from, state), do: {:reply, MockNIF, state}
    end

    defmodule MockNIF do
      def audio_subscribe(_room_ref, _track_sid, _subscriber_pid),
        do: {:ok, make_ref()}
      def audio_publish_frame(_room_ref, _data, _sr, _ch), do: :ok
    end

    defmodule MockPipeline do
      use GenServer
      def start_link(test_pid), do: GenServer.start_link(__MODULE__, test_pid)
      def init(test_pid), do: {:ok, test_pid}
      def handle_cast({:push_frame, frame}, test_pid) do
        send(test_pid, {:push_frame_called, frame})
        {:noreply, test_pid}
      end
    end
    ```

    Define these modules inside the test file (before the `defmodule RoomIOTest` block)
    to avoid polluting the global namespace.

    ## Test Cases

    Write at least 10 ExUnit tests covering:

    1. **start_link success** — starts with valid config, process alive
    2. **init subscribes to room events** — after start_link, MockRoom should have the
       RoomIO pid in its subscribers list
    3. **missing config returns error** — start_link with nil room_pid returns {:error, _}
    4. **auto-subscribe on :track_subscribed audio** — send {:track_subscribed, "TR_001", "alice", :audio},
       assert next :audio_frame is forwarded to pipeline (MockPipeline receives {:push_frame_called, _})
    5. **ignores non-audio :track_subscribed** — send {:track_subscribed, "TR_v", "alice", :video},
       assert RoomIO does NOT call AudioTrack.subscribe (no {:push_frame_called, _} message arrives)
    6. **audio_frame forwarded to Pipeline** — subscribe first, then send {:audio_frame, sid, binary},
       assert MockPipeline receives {:push_frame_called, %AudioFrame{data: ^binary, format: :pcm_16}}
    7. **pipeline_audio triggers AudioTrack.publish** — send {:pipeline_audio, %AudioFrame{data: <<1,2>>, format: :pcm_16}},
       assert :ok (no crash); MockNIF.audio_publish_frame was called (verify via metrics or no error log)
    8. **participant_disconnected resets track** — subscribe, then send {:participant_disconnected, "alice"},
       then send another audio_frame; assert it is still forwarded (RoomIO re-subscribes next track_subscribed)
       OR assert subscribed_track was reset to nil by checking metrics or next :track_subscribed causes new subscribe
    9. **get_metrics returns correct counts** — push several audio frames, assert frames_received increments
    10. **stop/1 terminates cleanly** — RoomIO.stop(pid), assert Process.alive?(pid) == false

    ## Test Helpers

    ```elixir
    setup do
      {:ok, room_pid} = MockRoom.start_link()
      {:ok, pipeline_pid} = MockPipeline.start_link(self())
      config = %RoomIO.Config{room_pid: room_pid, pipeline_pid: pipeline_pid}
      {:ok, room_io_pid} = RoomIO.start_link(config)
      %{room_io_pid: room_io_pid, room_pid: room_pid, pipeline_pid: pipeline_pid}
    end
    ```

    Use `Process.sleep(10)` after sending messages to give the GenServer time to process
    before asserting state changes. Prefer `assert_receive {:push_frame_called, _}, 100`
    over polling.

    ```elixir
    defmodule AgentSessionTest.MockNIF do
      def room_connect(_url, _token, _pid), do: {:ok, make_ref()}
      def room_disconnect(_room_ref), do: :ok
      def audio_subscribe(_room_ref, _track_sid, _pid), do: {:ok, make_ref()}
      def audio_publish_frame(_room_ref, _data, _sr, _ch), do: :ok
    end
    ```
