**Design decisions (Claude's Discretion from CONTEXT.md):**
- Target sample rate: 48,000 Hz (matches `Livekit.Agents.AudioFrame` default; `NativeAudioStream` handles resampling internally — don't hand-roll resampling)
- Target channels: 1 (mono) — the pipeline works with mono; stereo adds complexity with no benefit for STT/TTS
- `queue_size_frames`: `Some(480)` (10ms worth of frames at 48kHz) — small queue prevents memory buildup
- Dirty scheduler for `audio_subscribe`: YES — looking up the track in `Room` may involve async operations
- Audio binary format: `Vec<i16>` → `to_le_bytes()` → Elixir binary (Pitfall 5 in RESEARCH.md)

**native/livekit_webrtc/src/audio.rs:**
```rust
use std::time::Duration;

use futures::StreamExt;
use livekit::{
    options::TrackPublishOptions,
    track::{LocalAudioTrack, LocalTrack, RemoteAudioTrack, Track},
    webrtc::{
        audio_frame::AudioFrame,
        audio_source::{AudioSourceOptions, RtcAudioSource},
        audio_stream::native::NativeAudioStream,
        native::audio_source::NativeAudioSource,
    },
};
use rustler::{Encoder, LocalPid, OwnedEnv, ResourceArc};

use crate::atoms;
use crate::resources::{AudioTrackResource, RoomResource};

const TARGET_SAMPLE_RATE: i32 = 48_000;
const TARGET_CHANNELS: i32 = 1;
// 10ms of audio frames at 48kHz mono
const QUEUE_SIZE_FRAMES: usize = 480;
// Timeout guard against the known capture_frame blocking bug (RESEARCH.md Pitfall 2)
const CAPTURE_FRAME_TIMEOUT_MS: u64 = 500;

#[rustler::nif(schedule = "DirtyIo")]
pub fn audio_subscribe(
    room: ResourceArc<RoomResource>,
    track_sid: String,
    subscriber_pid: LocalPid,
) -> Result<ResourceArc<AudioTrackResource>, rustler::Error> {
    let sid = track_sid.clone();

    // Find the remote audio track in the room's participant list
    let audio_track = find_remote_audio_track(&room, &track_sid)
        .ok_or_else(|| rustler::Error::RaiseTerm(Box::new(format!("track not found: {}", track_sid))))?;

    let pid = subscriber_pid;

    let stream_task = crate::runtime::spawn(async move {
        let rtc_track = audio_track.rtc_track();
        let mut stream = NativeAudioStream::new(
            rtc_track,
            TARGET_SAMPLE_RATE,
            TARGET_CHANNELS,
            Some(QUEUE_SIZE_FRAMES),
        );

        while let Some(frame) = stream.next().await {
            // Convert Vec<i16> to little-endian bytes — MUST use to_le_bytes()
            // to match Livekit.Agents.AudioFrame :pcm_16 format (Pitfall 5)
            let bytes: Vec<u8> = frame.data.iter()
                .flat_map(|s| s.to_le_bytes())
                .collect();

            let track_sid = sid.clone();
            let mut env = OwnedEnv::new();
            // Safe: called from tokio worker thread, not a BEAM scheduler thread (Pitfall 1)
            let _ = env.send_and_clear(&pid, move |env| {
                (atoms::audio_frame(), track_sid, bytes).encode(env)
            });
        }
    });

    Ok(ResourceArc::new(AudioTrackResource {
        stream_task: stream_task.abort_handle(),
        track_sid,
        listener_pid: subscriber_pid,
    }))
}

/// Find a RemoteAudioTrack by its SID across all remote participants in the room.
fn find_remote_audio_track(room: &RoomResource, track_sid: &str) -> Option<RemoteAudioTrack> {
    for participant in room.room.remote_participants().values() {
        for track_pub in participant.track_publications().values() {
            if track_pub.sid() == track_sid {
                if let Some(track) = track_pub.track() {
                    if let livekit::track::RemoteTrack::Audio(audio_track) = track {
                        return Some(audio_track);
                    }
                }
            }
        }
    }
    None
}

#[rustler::nif(schedule = "DirtyIo")]
pub fn audio_publish_frame(
    room: ResourceArc<RoomResource>,
    audio_binary: rustler::Binary,
    sample_rate: u32,
    channels: u32,
) -> rustler::Atom {
    // Convert incoming little-endian int16 bytes back to Vec<i16>
    // This is the inverse of the subscribe path's to_le_bytes() conversion
    let bytes = audio_binary.as_slice();
    let samples: Vec<i16> = bytes
        .chunks_exact(2)
        .map(|chunk| i16::from_le_bytes([chunk[0], chunk[1]]))
        .collect();

    let samples_per_channel = (samples.len() / channels as usize) as u32;

    let result = crate::runtime::TOKIO.block_on(async {
        // Create a NativeAudioSource (done per-call for simplicity;
        // a production implementation would cache the source per room)
        let source = NativeAudioSource::new(
            AudioSourceOptions {
                echo_cancellation: false,
                noise_suppression: false,
                auto_gain_control: false,
            },
            sample_rate,
            channels,
            100, // queue_size_ms
        );

        let track = LocalAudioTrack::create_audio_track(
            "agent_audio",
            RtcAudioSource::Native(source.clone()),
        );

        // Publish the track to the room
        room.room
            .local_participant()
            .publish_track(LocalTrack::Audio(track), TrackPublishOptions::default())
            .await
            .ok();

        let frame = AudioFrame {
            data: samples.into(),
            sample_rate,
            num_channels: channels,
            samples_per_channel,
        };

        // Guard against the known capture_frame blocking bug (RESEARCH.md Pitfall 2)
        tokio::time::timeout(
            Duration::from_millis(CAPTURE_FRAME_TIMEOUT_MS),
            source.capture_frame(&frame),
        )
        .await
    });

    match result {
        Ok(Ok(_)) => atoms::ok(),
        Ok(Err(_)) => atoms::error(),
        Err(_timeout) => atoms::error(), // timeout elapsed — return error atom, don't block
    }
}
```

**Note on audio_publish_frame design:** Creating a new NativeAudioSource + LocalAudioTrack per `audio_publish_frame` call is intentionally simple for this phase. Plan 12 (RoomIO integration) will refactor this to cache the local audio track per room. The NIF interface (`audio_publish_frame/4`) stays identical so Plan 12 changes only the Rust implementation.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-10 | Denial of Service | `capture_frame` blocking indefinitely (Pitfall 2) | mitigate | `tokio::time::timeout(500ms, capture_frame)` — times out and returns error atom instead of hanging |
| T-11-11 | Denial of Service | Audio stream task producing frames faster than Elixir processes them | mitigate | `queue_size_frames: Some(480)` limits the NativeAudioStream internal buffer; frames are dropped at source if queue full, not accumulated |
| T-11-12 | Tampering | Malformed `audio_binary` (odd byte count) passed to `audio_publish_frame` | mitigate | `chunks_exact(2)` silently skips the trailing odd byte; add validation in Elixir wrapper (Plan 04) to reject non-even binaries |
| T-11-13 | Elevation of Privilege | `track_sid` lookup iterates all remote participants | accept | Room is trusted server data; track SID lookup is read-only with no side effects |
| T-11-14 | Denial of Service | `NativeAudioSource` + `LocalAudioTrack` created per `audio_publish_frame` call | accept | Known limitation noted in action — Plan 12 refactors to cached source; acceptable for Phase 11 scope |
