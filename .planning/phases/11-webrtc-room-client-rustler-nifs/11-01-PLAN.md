**native/livekit_webrtc/src/runtime.rs:**
The global tokio runtime MUST use `once_cell::sync::Lazy` — never create a runtime per NIF call or per Room. `OwnedEnv::send_and_clear` will only be called from tasks spawned into this runtime (BEAM-managed threads would panic, per Pitfall 1 in RESEARCH.md).
```rust
use once_cell::sync::Lazy;
use tokio::runtime::{Builder, Runtime};

pub static TOKIO: Lazy<Runtime> = Lazy::new(|| {
    Builder::new_multi_thread()
        .enable_all()
        .build()
        .expect("Failed to build global tokio runtime for livekit_webrtc NIF")
});

pub fn spawn<F>(future: F) -> tokio::task::JoinHandle<F::Output>
where
    F: std::future::Future + Send + 'static,
    F::Output: Send + 'static,
{
    TOKIO.spawn(future)
}
```

**native/livekit_webrtc/src/resources.rs:**
Resource structs wrapping Rust handles. `AbortHandle` cancels the event forwarding task when the Elixir process holding the `ResourceArc` is GC'd (D-04, D-11). `AudioTrackResource` holds the abort handle for a per-track audio streaming task.
```rust
use rustler::{LocalPid, Resource};
use tokio::task::AbortHandle;
use std::sync::Arc;
use livekit::Room;

pub struct RoomResource {
    pub room: Arc<Room>,
    pub event_task: AbortHandle,
    pub listener_pid: LocalPid,
}

#[rustler::resource_impl]
impl Resource for RoomResource {
    const IMPLEMENTS_DOWN: bool = true;

    fn down<'a>(&'a self, _env: rustler::Env<'a>, _pid: LocalPid, _mon: rustler::Monitor) {
        // Elixir process holding this ref died — stop the event forwarding task
        self.event_task.abort();
    }
}

pub struct AudioTrackResource {
    pub stream_task: AbortHandle,
    pub track_sid: String,
}

#[rustler::resource_impl]
impl Resource for AudioTrackResource {}
```

defmodule Livekit.WebRTC.Native do
  @moduledoc """
  NIF bindings to the LiveKit WebRTC Rust client SDK.

  This module is loaded automatically via `@on_load` when the application
  starts. All functions raise `ErlangError` if the NIF is not loaded —
  this should never happen in normal operation.

  Do not call these functions directly from application code; use
  `Livekit.WebRTC.Room` and `Livekit.WebRTC.AudioTrack` instead.
  """

  use Rustler, otp_app: :livekit, crate: :livekit_webrtc

  # Room NIFs
  @doc "Connect to a LiveKit room. Returns an opaque room resource reference."
  @spec room_connect(String.t(), String.t(), pid()) :: {:ok, reference()} | {:error, String.t()}
  def room_connect(_url, _token, _listener_pid),
    do: :erlang.nif_error(:nif_not_loaded)

  @doc "Disconnect from a LiveKit room and stop the event forwarding task."
  @spec room_disconnect(reference()) :: :ok
  def room_disconnect(_room_ref),
    do: :erlang.nif_error(:nif_not_loaded)

  # Audio NIFs
  @doc "Subscribe to a remote audio track. Starts streaming {:audio_frame, track_sid, binary} to subscriber_pid."

    do: :erlang.nif_error(:nif_not_loaded)

  @doc "Publish a PCM int16 audio frame to the room's local audio track."

  def audio_publish_frame(_room_ref, _audio_binary, _sample_rate, _channels),
    do: :erlang.nif_error(:nif_not_loaded)
end

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Elixir→NIF | Elixir passes url/token strings and PIDs across the NIF boundary |
| NIF→Rust heap | ResourceArc manages lifetimes; BEAM GC notifies via `down` callback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Denial of Service | `room_connect` DirtyIo scheduler | mitigate | `schedule = "DirtyIo"` keeps BEAM schedulers unblocked; `TOKIO.block_on` only runs on dirty thread |
| T-11-02 | Elevation of Privilege | Global tokio runtime shared across rooms | accept | Runtime is stateless; all room state is in per-`ResourceArc` structs; no cross-room data access |
| T-11-03 | Denial of Service | NIF panic crashing the BEAM | mitigate | Rust panics in NIFs are caught by Rustler and converted to Erlang exceptions (not VM crashes) since Rustler 0.30+ |
| T-11-04 | Tampering | `AbortHandle` in RoomResource | accept | Only the Rust `down` callback (called by BEAM GC) can abort the task; no Elixir code can abort it directly |
</threat_model>
