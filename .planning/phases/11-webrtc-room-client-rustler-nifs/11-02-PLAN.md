<objective>
Implement the `room_connect` and `room_disconnect` NIF functions that drive the LiveKit room lifecycle. `room_connect` blocks on a DirtyIo scheduler thread to run `Room::connect`, then spawns a long-lived tokio task that reads `RoomEvent` from the MPSC receiver and forwards each event as an Erlang message to the registered listener PID. `room_disconnect` aborts the event task and calls `room.disconnect()`.

**Critical constraints from RESEARCH.md:**
- `OwnedEnv::send_and_clear` MUST only be called from tokio threads (Pitfall 1). The event loop task is spawned via `crate::runtime::spawn` which puts it on a tokio worker thread — this is correct.
- `DirtyIo` scheduler attribute is required on `room_connect` since `TOKIO.block_on` can take hundreds of ms (Pitfall noted in research: >1ms NIF must use dirty scheduler).
- Store `rx` (the `UnboundedReceiver<RoomEvent>`) INSIDE the async task — do NOT assign to `_`. If the receiver is dropped, all events are silently lost (Pitfall 6).
- Use `RoomOptions { auto_subscribe: true, ..Default::default() }` so remote tracks are automatically subscribed.

**native/livekit_webrtc/src/room.rs:**
```rust
use std::sync::Arc;

use livekit::{Room, RoomEvent, RoomOptions};
use rustler::{LocalPid, OwnedEnv, ResourceArc};

use crate::atoms;
use crate::resources::RoomResource;

#[rustler::nif(schedule = "DirtyIo")]
pub fn room_connect(
    url: String,
    token: String,
    listener_pid: LocalPid,
) -> Result<ResourceArc<RoomResource>, rustler::Error> {
    // Block on DirtyIo thread — safe because dirty threads are not BEAM schedulers.
    // TOKIO.block_on runs the future to completion synchronously on this thread.
    let result = crate::runtime::TOKIO.block_on(async {
        Room::connect(
            &url,
            &token,
            RoomOptions {
                auto_subscribe: true,
                ..Default::default()
            },
        )
        .await
    });

    let (room, rx) = result.map_err(|e| {
        rustler::Error::RaiseTerm(Box::new(e.to_string()))
    })?;

    let room = Arc::new(room);
    let pid = listener_pid;

    // Spawn event forwarding task on the global tokio runtime.
    // The task OWNS `rx` — never assign rx to `_` or events are silently lost (Pitfall 6).
    // `send_and_clear` is safe here because tokio worker threads are not BEAM-managed.
    let event_task = crate::runtime::spawn(async move {
        let mut rx = rx;
        while let Some(event) = rx.recv().await {
            forward_room_event(&pid, event);
        }
    });

    Ok(ResourceArc::new(RoomResource {
        room,
        event_task: event_task.abort_handle(),
        listener_pid,
    }))
}

#[rustler::nif(schedule = "DirtyIo")]
pub fn room_disconnect(room: ResourceArc<RoomResource>) -> rustler::Atom {
    // Abort the event forwarding task first
    room.event_task.abort();
    // Graceful disconnect from LiveKit server
    crate::runtime::TOKIO.block_on(async {
        room.room.disconnect().await.ok();
    });
    atoms::ok()
}

/// Forward a single RoomEvent to the Elixir listener PID as an Erlang message.
///
/// Each arm creates a fresh OwnedEnv (cheap allocation) and calls send_and_clear.
/// This is called from a tokio worker thread — never from a BEAM scheduler thread.
fn forward_room_event(pid: &LocalPid, event: RoomEvent) {
    let mut env = OwnedEnv::new();
    match event {
        RoomEvent::ParticipantConnected(p) => {
            let identity = p.identity().to_string();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::participant_connected(), identity).encode(env)
            });
        }
        RoomEvent::ParticipantDisconnected(p) => {
            let identity = p.identity().to_string();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::participant_disconnected(), identity).encode(env)
            });
        }
        RoomEvent::TrackSubscribed { track, publication, participant } => {
            let track_sid = publication.sid().to_string();
            let identity = participant.identity().to_string();
            let track_kind = format!("{:?}", track.kind());
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::track_subscribed(), track_sid, identity, track_kind).encode(env)
            });
        }
        RoomEvent::TrackUnsubscribed { track: _, publication, participant } => {
            let track_sid = publication.sid().to_string();
            let identity = participant.identity().to_string();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::track_unsubscribed(), track_sid, identity).encode(env)
            });
        }
        RoomEvent::TrackPublished { publication, participant } => {
            let track_sid = publication.sid().to_string();
            let identity = participant.identity().to_string();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::track_published(), track_sid, identity).encode(env)
            });
        }
        RoomEvent::TrackUnpublished { publication, participant } => {
            let track_sid = publication.sid().to_string();
            let identity = participant.identity().to_string();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::track_unpublished(), track_sid, identity).encode(env)
            });
        }
        RoomEvent::DataReceived { payload, topic, kind: _, participant } => {
            let bytes = payload.to_vec();
            let topic_str = topic.unwrap_or_default();
            let identity = participant.map(|p| p.identity().to_string()).unwrap_or_default();
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::data_received(), bytes, topic_str, identity).encode(env)
            });
        }
        RoomEvent::ConnectionQualityChanged { quality, participant } => {
            let identity = participant.identity().to_string();
            let quality_str = format!("{:?}", quality);
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::connection_quality_changed(), identity, quality_str).encode(env)
            });
        }
        RoomEvent::Disconnected { reason } => {
            let reason_str = format!("{:?}", reason);
            let _ = env.send_and_clear(pid, move |env| {
                (atoms::disconnected(), reason_str).encode(env)
            });
        }
        // Silently ignore events not listed in D-12 (e.g. RoomMetadataChanged)
        _ => {}
    }
}
```

use rustler::{LocalPid, Resource};
use tokio::task::AbortHandle;
use std::sync::Arc;
use livekit::Room;

pub struct RoomResource {
    pub room: Arc<Room>,
    pub event_task: AbortHandle,
    pub listener_pid: LocalPid,
}

#[rustler::resource_impl]
impl Resource for RoomResource {
    const IMPLEMENTS_DOWN: bool = true;

    fn down<'a>(&'a self, _env: rustler::Env<'a>, _pid: LocalPid, _mon: rustler::Monitor) {
        // Elixir process holding this reference was GC'd — stop the event task.
        self.event_task.abort();
    }
}

pub struct AudioTrackResource {
    pub stream_task: AbortHandle,
    pub track_sid: String,
    pub listener_pid: LocalPid,
}

#[rustler::resource_impl]
impl Resource for AudioTrackResource {
    const IMPLEMENTS_DOWN: bool = true;

    fn down<'a>(&'a self, _env: rustler::Env<'a>, _pid: LocalPid, _mon: rustler::Monitor) {
        // Elixir process that subscribed to this track died — stop the audio stream.
        self.stream_task.abort();
    }
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Elixir→NIF (room_connect) | url and token strings cross NIF boundary untrusted |
| tokio task→BEAM PID | OwnedEnv::send_and_clear crosses from Rust thread to Elixir process |
| LiveKit server→RoomEvent | Events from remote server arrive via Room::connect MPSC receiver |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05 | Spoofing | `listener_pid` stored in RoomResource | accept | PIDs are opaque BEAM references; Rust cannot forge them; the caller must be the legitimate room owner |
| T-11-06 | Denial of Service | Event forwarding loop blocking on `rx.recv()` | accept | `rx.recv()` is an async await point — it yields to tokio; no BEAM scheduler impact |
| T-11-07 | Information Disclosure | RoomEvent data forwarded to Elixir PID | accept | Only the registered `listener_pid` receives events; no broadcast |
| T-11-08 | Denial of Service | Unbounded `OwnedEnv` allocations if events arrive faster than Elixir processes them | mitigate | Elixir GenServer message queue is bounded by memory; add `handle_info` catchall clause in Plan 04 to prevent mailbox overflow |
| T-11-09 | Tampering | Token passed as plain string to `Room::connect` | accept | Token is a signed JWT; the LiveKit server validates it; NIF merely passes it through |
</threat_model>
